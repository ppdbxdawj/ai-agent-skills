# 故事结构与 AI 辅助策划（让 IP 立起来）

把一个角色变成 IP，靠的不是造型，是**故事**。这套方法回答："怎么才能让一个角色变成能在很长时间、很多地方、被很多人记住的 IP？" —— 让它身上有故事。

## 三条底层信念（先内化）

1. **漂亮 ≠ 有故事，造型 ≠ IP。** AI 每天生成成千上万"漂亮女孩"，没人记住；米老鼠、哆啦 A 梦、LABUBU、哪吒被记住，是因为身上有"感觉得到"的故事。
2. **故事 = 因果链 + 情感曲线。** 镜头之间连的若是"然后"，就是流水账；连的是"但是/所以"，才有戏剧性。很多 AI 短视频败在"画面很美但没因果，看完没情绪"。
3. **会用 AI 是入场券，会讲故事是分水岭。** 漂亮、新奇、技术含量 AI 都能复制；只有"独特情感经验"和"为什么要讲这个故事"复制不了——那来自创作者的人生与价值观，是人机之间不可让渡的边界。

形象的维度递增是几何级而非线性：1 维（只有形象）→ 2 维（形象+故事）→ 3 维（形象+故事+主题），影响力是 ×10、×100。

## 何时用本技能

- 设计 IP / 角色，或被问"这个角色/故事为什么立不住、不抓人"
- 写短视频 / 短片 / 短剧 / 剧本 / 概念片的剧情骨架
- 要和 AI 协作策划一个故事（人定方向、AI 出候选）
- 给作品做"拉片"式拆解分析
- 做二创 / 混剪 / 同人 / 鬼畜 / 短剧 / 剧本杀 / 单元剧 / AI 互动影游 / 解说 的内容策划

## 工作流总览

```
① 体检：用"故事五问"给现有创意/角色挑硬伤
② 选骨架：按作品长度选一种结构（默认 Harmon 8 步）
③ 写故事：用所选结构一步步推演骨架（人机协作）
④ 拉片自检：把成片当机械装置拆开，验证每个功能是否到位
```

## ① 故事五问体检表（核心工具）

任何故事动笔前先回答这五问。好莱坞、Pixar、Netflix 通用的"剧本体检表"。八成作品的硬伤在这一步现形。

| 问题 | 缺了会怎样 | 一句话标准 |
|---|---|---|
| Q1 主角是谁？ | 没主角 → 没焦点 | 招人喜欢（≠善良）+ 是某种欲望的化身 + 成功胜算 30–40% + 有"种子能力" |
| Q2 目标是什么？ | 没目标 → 没方向 | 三层：事件目标（可验证）/ 情感目标（真实渴望）/ 价值观目标（主题）。且观众也想要 |
| Q3 谁在阻碍主角？ | 没阻碍 → 没冲突 | 三层叠加：外部（环境）+ 个人（对手，最好是镜像）+ 内心（恐惧/创伤，最打动人） |
| Q4 代价是什么？ | 没代价 → 没分量 | 失败会触及某种"死亡气息"：字面/身份/关系/精神死亡。具象+抽象叠加最狠 |
| Q5 为什么是现在？ | 没时机 → 没起点 | 有一个**激励事件**把"平稳的陀螺"推歪：意外发生 / 主角决定 / 主角醒悟 |

> 自检动作：拿你正在做的角色，对这五问逐条作答；Q4 若写不出 3 行，代价设计就不够。

每一问的深挖（三层结构、案例、AI 角色常见硬伤）见 [references/five-questions.md](references/five-questions.md)。

## ② 选哪种结构

结构本质只有 1 种——**平衡被打破 → 主角行动 → 阻力升级 → 触底 → 重生 → 归来**；六套理论只是用不同颗粒度切它。按作品长度选：

| 作品长度 | 推荐结构 |
|---|---|
| 15 秒–3 分钟（短视频） | Harmon 8 步圆环 |
| 3–15 分钟（短片） | Harmon 8 步 + 三幕骨架 |
| 90–150 分钟（标准长片） | 救猫咪 15 节拍 |
| 史诗 / 多部曲 | 英雄之旅 + 五幕式 |
| 系列剧 | 每集 Harmon，每季英雄之旅嵌套 |

学习顺序：① McKee 五核心（懂底层）→ ② Harmon 8 步（最简单实用）→ ③ 练短片 → ④ 长片上救猫咪 → ⑤ IP 系列上英雄之旅。**先学会，再打破**：所有打破结构的大师都是先把结构练到极致才反着用的。

六套结构的完整对照表、节拍表、案例见 [references/structures.md](references/structures.md)。

## ③ 用 Harmon 8 步现场写故事（默认工作流）

Dan Harmon 把英雄之旅压成 8 步圆环，上半圆"熟悉世界"、下半圆"陌生世界"，主角绕一圈回到起点但已变成新的自己。短内容首选。

| # | 步骤 | 含义 |
|---|---|---|
| 1 | You 角色 | 一个角色，处于舒适区 |
| 2 | Need 需要 | 他有某种需求或不满（注意 Want≠Need） |
| 3 | Go 出发 | 踏出舒适区 |
| 4 | Search 寻找 | 在新世界适应、试错、挣扎 |
| 5 | Find 找到 | 找到他真正需要的（**中点反转**） |
| 6 | Take 代价 | 拿走它必须付出的代价 |
| 7 | Return 归来 | 带着代价回到熟悉世界 |
| 8 | Change 改变 | 已经不是出发时那个人 |

五条实战贴士：
1. **别在第 1 步纠结**——Step 1 一句话、可模糊；后 7 步会反过来帮你完善它。故事是写出来的，不是想出来的。
2. **Find 和 Take 是灵魂，务必反转**——Step 5/6 是转折机器，没"价值翻转"故事就没重量。Find 要"意外但回头看必然"，Take 要逼主角付出没想付的代价。
3. **主题在结尾长出来**——别强行"动笔前定主题"，主题往往写到 Step 8 回头看才浮现。放心写，主题会找你。
4. **卡住时反向问**——Step 4 写不出，就问"如果他在新世界什么都没找到会怎样？"
5. **人机协作边界（关键）**：

```
Step 1 + Step 2 → 你来定（这是"为什么写"，主体性，不可让给 AI）
Step 3–7        → 让 AI 生成 3–7 个候选方案
Step 8          → 你挑选并改写
```

> 故事不是 AI 写的，是你**借助** AI 写的。

## ④ 拉片自检（成片后或评估他人作品）

"拉片"=用创作者视角，把故事当机械装置打开、逐镜头逐场景拆。是从"会看故事"到"会做故事"的桥梁。最小自检：

1. **一句话讲全片**（高概念 logline）：`当〔触发事件〕时，一个〔主角特征〕必须〔行动〕，否则〔代价〕。` 写不出这句 → 结构没立住。
2. **用五问逐条回答**这部片（每答配一张关键截图）。
3. **挑一个关键场景细拆**：它属于哪个节拍？同时承担哪些功能（推进情节/暴露人物/重申主题/制造冲突/视觉美感）？镜头与配乐如何为故事服务？倒回去你会怎么改？
4. **看弧光与主题**：主角从 A 到 B 的内在变化、表层/中层/深层主题、结尾画面与开场画面的呼应。

拉片框架详版见 [references/worked-example.md](references/worked-example.md)。

## 让观众"坐得住、看得完、记得久"

- **进得来**：开场让观众"在乎"主角命运（经典手法"救猫咪"：开场 10 分钟内让主角做一件小善事）。
- **走不掉**：麻烦要不断**升级**而非重复（失业→失家→失尊严→失自我，而不是失业→失业→失业）。外部钩子三选其一拉满：**奇观**（前所未见的视觉，AI 红利）/ **氛围**（光色声节奏的浓度）/ **好玩**（反转、机灵——AI 最难独立产生，是创作者护城河）。
- **离场爽**：结尾给观众一次情绪释放（哭/笑/长舒一口气/沉思）。

不同载体要"适配"方法论：二创、混剪、同人、鬼畜、短剧、剧本杀、单元剧、AI 互动影游、解说 —— 各自的精髓、推荐结构、实战建议，以及"我该做哪种"的决策树，见 [references/applications.md](references/applications.md)。

## 质量红线（交付前过一遍）

- [ ] 五问能逐条答出，Q4 代价写得出 ≥3 行
- [ ] 句子之间连的是"但是/所以"，不是"然后"
- [ ] 有明确的激励事件（陀螺被推歪的那一秒）
- [ ] Find/Take 有真正的价值翻转，主角付出了代价
- [ ] 主角有可见的弧光（A→B），结尾与开场呼应
- [ ] 阻碍至少触及"内心"那一层，不只是外部环境
- [ ] "为什么是你来讲这个故事"这一主体性没有外包给 AI
