# 六大故事结构（完整对照与套用）

故事结构本质只有 1 种：**平衡被打破 → 主角行动 → 阻力升级 → 触底 → 重生 → 归来**。下面六套理论用不同颗粒度切了它。对齐后关键节点完全一致：

```
开场建立 → 激励事件 → 中点反转 → 一无所有 → 高潮决战 → 结尾呼应
```

| 结构 | 颗粒度 |
|---|---|
| McKee 五核心 | 5 阶段 |
| 三幕式 | 3 段 |
| 五幕式 | 5 段 |
| 英雄之旅 | 12 阶段 |
| 救猫咪 | 15 节拍 |
| Harmon 圆环 | 8 步 |

---

## 1. McKee 五核心 —— 原子级骨架

来自罗伯特·麦基《故事》(1997)。能闭眼背出来，故事就有底了。

```
激励事件 → 进展纠葛 → 危机 → 高潮 → 结局
```

| 模块 | 占比 | 在干什么 |
|---|---|---|
| 激励事件 | 10–15% | 打破主角的生活平衡 |
| 进展纠葛 | 60–70% | 一连串"越来越难"的阻碍 |
| 危机 | 短 | 主角面对一个两难选择 |
| 高潮 | 短 | 主角做出选择后的最后行动 |
| 结局 | 5–10% | 收尾、和开头呼应 |

两位现代编剧学奠基人：
- **麦基**："故事是生活的隐喻"——不是抄写生活，是把又乱又长的生活提纯成 90 分钟一条清晰的因果线。
- **埃格里**（《戏剧写作的艺术》）：每个故事都得有一句"前提"（核心论点）。例：《麦克白》="贪婪导致自我毁灭"；《罗密欧与朱丽叶》="伟大的爱情连死亡都挡不住"；《老人与海》="不屈服的人即使失败也是胜利"。写之前先把这一句想清楚。

更早的祖师爷**亚里士多德《诗学》**：① 故事是"对行动的模仿"（讲他做了什么，不是长什么样）；② 好故事让观众"洗一遍心"（净化/catharsis）；③ 六要素重要性排序：**情节 > 性格 > 思想 > 言辞 > 歌曲 > 形象**——形象排最后，和"先做造型再编故事"正好相反。

## 2. 三幕式 —— 好莱坞的宪法

过去 50 年 90%+ 商业电影遵守。系统化者 Syd Field (1979)。按 120 分钟算：

- **第一幕·铺垫**（0–25%，约 30 分钟）：介绍世界、介绍主角、抛出激励事件
- **第二幕·对抗**（25–75%，约 60 分钟）：主角追目标的主体战斗
- **第三幕·解决**（75–100%，约 30 分钟）：最后冲刺、高潮、结局

四个不可错过的打卡点：

| 节点 | 时间点 | 在干什么 |
|---|---|---|
| 激励事件 | 第 10–15 分钟 | 主角的生活被打破 |
| 第一情节点 | 第 25–27 分钟 | 主角真正踏上旅程，回不去了 |
| 中点 | 第 60 分钟 | 一个重大反转 |
| 第二情节点 | 第 85–90 分钟 | 主角陷入最低谷（"灵魂黑夜"） |

**不归点**：每一幕结尾主角都做一个回不去的决定（Frodo 决定带魔戒离开夏尔 / 安迪决定开始挖通道 / Luke 关闭瞄准计算机凭原力射击）。不归点要"绝"——常见毛病是不够绝，观众的心一直悬着。

### ABCD 公式：但是 / 所以（来自《南方公园》主创）

> 某人想要 A，**所以**做了 B，**但是**发生了 C，**因此**不得不做 D。

关键是连接词："所以"=因果，"但是"=冲突。**句子之间连"然后"就是流水账；连"但是/所以"才有戏剧性。** 例（《海底总动员》开场）：Marlin 想保护儿子 Nemo，所以禁止他远离珊瑚礁，但是 Nemo 叛逆游向大海被人类抓走，因此 Marlin 不得不开始一段穿越大海的拯救之旅。检查任何卡顿的故事——卡顿处都是"然后"在做连接，换成"但是/所以"立刻就活。

## 3. 五幕式 —— 古典金字塔

古希腊悲剧都是五幕。

```
铺垫 → 上升 → 高潮 → 下降 → 收场
```

和三幕最大差别：**高潮在中间，不是结尾！** 后两幕处理高潮的余波（这就是《教父》迈克成为教父之后才真正打动人——那是他的 falling action）。现在仍在用：史诗作品（《指环王》三部曲）、文艺片/作者电影、中国 40 集电视剧（"拓展五幕 + 多重小高潮"）。

## 4. 英雄之旅 —— 神话的通用结构

1949 年坎贝尔《千面英雄》横向对比各民族英雄神话，发现"所有英雄神话本质是同一个故事"。Christopher Vogler 简化成 12 阶段：

| # | 阶段 | 在干什么 |
|---|---|---|
| 1 | 寻常世界 | 主角原本的生活 |
| 2 | 冒险召唤 | 一个事件邀请主角离开 |
| 3 | 拒绝召唤 | 主角因恐惧而拒绝 |
| 4 | 遇到导师 | 一个智者出现 |
| 5 | 跨越门槛 | 正式踏入未知世界 |
| 6 | 考验·盟友·敌人 | 在新世界遇到一连串测试 |
| 7 | 接近洞穴 | 逼近核心威胁 |
| 8 | 磨难 | 象征性的"死亡" |
| 9 | 奖励 | 穿越磨难拿到回报 |
| 10 | 归路 | 带着回报开始返回 |
| 11 | 复活 | 归途上最终考验，重生 |
| 12 | 带胜利果实归来 | 改变世界的"仙丹" |

案例：《星球大战》卢克离开沙漠星球→遇欧比旺（导师）→跨越门槛→直面维德（磨难）→学会原力（复活）→摧毁死星（归来）。《千与千寻》进入隧道→锅炉爷爷/小玲（导师）→桥的另一边（门槛）→汤婆婆/无脸男（考验）→救白龙记起名字（复活）→走出隧道（归来）。它也是心理学原型：观众潜意识重温自己"被迫离开舒适区、面对恐惧、获得成长"的瞬间。

## 5. 救猫咪 —— 把结构当工程图纸

Blake Snyder 的"工业派"，精确到页码。三幕式细化为 15 节拍（按 110 页剧本）：

| # | 节拍 | 页码 |
|---|---|---|
| 1 | 开场画面 | 第 1 页 |
| 2 | 主题陈述 | 第 5 页 |
| 3 | 铺垫 | 1–10 页 |
| 4 | 催化剂 | 第 12 页 |
| 5 | 争论 | 12–25 页 |
| 6 | 进入第二幕 | 第 25 页 |
| 7 | B 故事 | 第 30 页 |
| 8 | 玩乐时光 | 30–55 页 |
| 9 | 中点 | 第 55 页 |
| 10 | 反派逼近 | 55–75 页 |
| 11 | 一无所有 | 第 75 页 |
| 12 | 灵魂黑夜 | 75–85 页 |
| 13 | 进入第三幕 | 第 85 页 |
| 14 | 终局 | 85–110 页 |
| 15 | 结尾画面 | 第 110 页 |

好莱坞流水线需要这种精确性（制片人翻到第 25 页没看到"进入第二幕"，剧本直接退稿）。**AI 时代迁移用法**：把一个 3 分钟短片（180 秒）切成 15 个 12 秒片段，每段对应一个节拍——好莱坞工程学直接搬到 AI 时代。

## 6. Harmon 故事圆环 —— 8 步搞定（短内容首选）

Dan Harmon（《瑞克和莫蒂》主创）把英雄之旅压成 8 步：

| # | 步骤 | 含义 |
|---|---|---|
| 1 | You 角色 | 一个角色，处于舒适区 |
| 2 | Need 需要 | 他有某种需求或不满 |
| 3 | Go 出发 | 踏出舒适区 |
| 4 | Search 寻找 | 在新世界适应、试错 |
| 5 | Find 找到 | 找到他真正需要的 |
| 6 | Take 代价 | 拿走它必须付出代价 |
| 7 | Return 归来 | 带着代价回到熟悉世界 |
| 8 | Change 改变 | 已经不是出发时那个人 |

画成一个圆：上半圆"熟悉世界"，下半圆"陌生世界"。主角从 1 顺时针下降、在中点穿越、再上升回到起点——但 1 已变成新的 1。适合初学者的三个理由：① 8 步够少，20 分钟可完整推演一遍；② 每步功能明确，不跑偏；③ 圆环天然首尾呼应，收尾不会失败。**只想学一个工具，就学这个。**
