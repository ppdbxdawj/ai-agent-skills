# 小说主线 → 分镜脚本 → Seedance 提示词

## 整体流程（5大阶段）

```
小说原文
  ├─ Phase A: 物象提取（并行）
  │    ├─ A1. 角色档案分析 → 外貌/等级/服装/形象/age_gender_prompt
  │    └─ A2. 场景资产分析 → 环境/氛围/多视角描述/色调
  ├─ Phase B: 片段切分 → Clip 列表（含起止锚点、角色、场景）
  ├─ Phase C: 剧本转换（每个 Clip 并行）→ 标准剧本格式（动作/台词/VO/SFX/BGM）
  ├─ Phase D: 分镜规划（每个 Clip 4步）
  │    ├─ D1. 基础分镜 Panel 列表（景别/画面描述/角色）
  │    ├─ D2a. 摄影规则（灯光/色调/构图/景深）─ 并行
  │    ├─ D2b. 演技指导（微表情/姿态/身体语言）─ 并行
  │    └─ D3. 最终细化（shot_type/camera_move/video_prompt/audio）
  └─ Phase E: Seedance 提示词生成（每个 Clip → 一段 prompt）
       → 输出 EP{XX}-seedance-prompts.md（Seg1～Seg4 等）
       → 每集必出：EP{XX}-抖音发布说明-八角笼与系列导流.md
```

## Phase A：视觉物象提取

### A1. 角色档案分析

**LLM 任务指令模板**：

```
你是资深影视制作团队的角色档案师。请从以下小说原文中提取所有出场角色的视觉档案信息。

【小说原文】
{input}

【已有角色库】（不要重复提取这些角色，但如发现新信息可补充）
{characters_lib_info}

请以 JSON 格式输出，包含 new_characters 和 updated_characters 两个字段：

new_characters 每项包含：
- name: 角色姓名（规范名，非别名）
- aliases: 别名/称呼数组（如"我"、"他"等第一/三人称映射）
- introduction: 角色介绍（身份、与其他角色的关系、"我"指代的是谁）
- gender: 性别
- age_range: 年龄段（如"约三十岁"、"少女"）
- role_level: 重要级别 S/A/B/C（S=主角）
- archetype: 角色原型（如"霸道总裁"、"白月光"）
- personality_tags: 性格标签数组（3-5个）
- era_period: 时代背景（如"现代都市"）
- social_class: 社会阶层（如"上层精英"）
- occupation: 职业
- costume_tier: 服装精细度 1-5（5=极华丽）
- suggested_colors: 建议主色调数组
- primary_identifier: 最显眼的外观标识（如"眼角泪痣"）
- visual_keywords: 视觉风格关键词数组（3-5个）
- expected_appearances: 预计需要几套形象 [{id, change_reason}]
```

**输出示例**：

```json
{
  "new_characters": [
    {
      "name": "苏晴",
      "aliases": ["我", "她"],
      "introduction": "故事主角，以第一人称'我'叙述。顾司寒的妻子，外冷内热。",
      "gender": "女",
      "age_range": "约二十八岁",
      "role_level": "S",
      "archetype": "隐忍主母",
      "personality_tags": ["倔强", "隐忍", "聪慧", "温柔"],
      "era_period": "现代都市",
      "social_class": "中产",
      "occupation": "设计师",
      "costume_tier": 3,
      "suggested_colors": ["米白", "藕粉", "灰蓝"],
      "primary_identifier": "右耳三角形耳钉",
      "visual_keywords": ["知性", "清冷", "东方美人"],
      "expected_appearances": [
        {"id": 1, "change_reason": "日常居家"},
        {"id": 2, "change_reason": "正式场合"}
      ]
    }
  ],
  "updated_characters": []
}
```

### A2. 场景资产分析

**LLM 任务指令模板**：

```
你是资深影视场景设计师。请从小说原文中提取所有关键场景，并为每个场景生成3个不同视角的视觉描述，供后续图像生成使用。

【小说原文】
{input}

【已有场景库】（不要重复，但可补充新信息）
{locations_lib_name}

输出 JSON，locations 数组，每项包含：
- name: 场景名（格式：地点_时段，如"书房_夜晚"）
- summary: 场景简介（用途、氛围、在故事中的作用）

## Phase B：片段切分（Clip Segmentation）

**LLM 任务指令模板**：

```
你是资深影视剪辑师。请将小说原文切分为若干独立场景片段（Clip），每个 Clip 对应一个连续的时空单元。

要求：
- 时空切换时必须切分
- 每个 Clip 独立完整，不跨越时空
- 场景名必须来自场景库
- 角色名必须来自角色库
- start/end 用原文中的精确原句（10字以上）

【小说原文】
{input}

【场景库】{locations_lib_name}
【角色库】{characters_lib_name}
【角色介绍】（用于理解第一人称"我"对应谁）
{characters_introduction}

输出 JSON 数组，每项包含：
- start: 片段开头的精确原句
- end: 片段结尾的精确原句
- summary: 片段内容摘要（一句话）
- location: 场景名（来自场景库）
- characters: 出场角色名数组
```

**输出示例**：

```json
[
  {
    "start": "清晨六点，别墅的门铃响了三声。",
    "end": "我转身回房，轻轻带上了门。",
    "summary": "顾司寒突然回来，苏晴在门口与他短暂交锋后离开。",
    "location": "顾氏别墅门厅_清晨",
    "characters": ["苏晴", "顾司寒"]
  }
]
```

## Phase D：分镜规划（4步流程）

### D1. 基础分镜规划

**LLM 任务指令模板**：

```
你是资深分镜师。请根据剧本内容规划分镜，每个分镜对应一个具体画面。

【角色形象信息】
{characters_appearance_list}

【角色完整外观描述】
{characters_full_description}

【片段信息】
{clip_json}

【剧本内容】
{clip_content}

规划要求：
- 每个分镜对应1个单一画面，时长2-6秒
- 根据情绪选择 scene_type：daily/emotion/action/epic/suspense
- characters 中记录每个角色的形象编号（对应角色档案的 appearance id）
- source_text 摘录对应的原文片段

输出 JSON 数组，每项包含：
panel_number, description（画面描述100字），characters（[{name, appearance}]），
location, scene_type, source_text
```

### D2a. 摄影规则（与D2b并行）

**LLM 任务指令模板**：

```
你是资深摄影指导。请为以下分镜列表设计摄影规则。

【分镜列表】
{panels_json}（共{panel_count}个分镜）

【场景描述】
{locations_description}

【角色外观信息】
{characters_info}

为每个分镜输出 JSON 数组，每项包含：
- panel_number
- lighting: {direction, quality}（光线方向与质感）
- characters: [{name, screen_position, posture, facing}]（角色在画面中的位置）
- depth_of_field: 景深描述（如"浅景深T1.8"）
- color_tone: 色调描述（如"冷蓝调"）
```

### D2b. 演技指导（与D2a并行）

**LLM 任务指令模板**：

```
你是专业表演指导。请为以下分镜设计精确的演技细节。

【分镜列表】
{panels_json}（共{panel_count}个分镜）

【角色外观信息】
{characters_info}

为每个分镜输出 JSON 数组，每项包含：
- panel_number
- characters: [{name, acting}]（acting：描述角色的微表情、眼神、姿态、手部动作等，20-40字）
```

**演技描述示例**：`"嘴角微扬眼神柔和地看向对方，身体微微前倾，双手自然垂放，轻轻眨眼"`

### D3. 最终细化 + video_prompt

**LLM 任务指令模板**：

```
你是资深导演。请对以下分镜进行最终细化，并生成视频生成提示词。

【分镜列表】
{panels_json}（共{panel_count}个分镜）

【角色年龄性别信息】（用于video_prompt，必须用年龄段+性别替代角色名）
{characters_age_gender}

【场景描述】
{locations_description}

为每个分镜补充并输出完整 JSON：
- panel_number
- shot_type: 景别（如"平视中景"、"仰拍特写"、"俯瞰全景"）
- camera_move: 镜头运动（如"固定"、"缓缓推近"、"横移跟随"）
- description: 最终画面描述（含 shot_type 和 camera_move，120字）
- video_prompt: 视频生成提示词（英文或中文均可，关键规则见下）
- 保留原有的 characters/location/scene_type/source_text

video_prompt 核心规则：
⚠️ 必须用"年龄段+性别"替代所有角色名（视频模型不认识名字）
例："苏晴"→"二十八岁的东方女性"，"顾司寒"→"三十五岁的精英男性"
描述角色动作、场景氛围、镜头运动，不超过80字。
```

## 最终 Panel 数据结构

```typescript
interface StoryboardPanel {
  panel_number: number        // 分镜编号（1-based）
  shot_type: string           // 景别（如"平视中景"）
  camera_move: string         // 镜头运动（如"缓缓推近"）
  description: string         // 完整画面描述
  video_prompt: string        // 视频生成提示词（用年龄+性别替代角色名）
  characters: Array<{
    name: string              // 角色名
    appearance: number        // 形象编号（对应角色档案）
  }>
  location: string            // 场景名
  scene_type: 'daily' | 'emotion' | 'action' | 'epic' | 'suspense'
  source_text: string         // 对应原文片段
  // 合并自 D2a/D2b
  photographyPlan: {
    lighting: string
    colorPalette: string
    atmosphere: string
    technicalNotes: string    // ← Phase E 转换时必须写入 prompt
  }
  actingNotes: Array<{
    name: string
    acting: string            // 微表情/姿态描述 ← Phase E 转换时必须写入 prompt
  }>
  audio: {                    // Phase D3 新增，Phase E 按段写入
    dialogue: Array<{
      type: 'dialogue' | 'voiceover'
      character: string
      text: string
      voice_note: string      // 音色+情绪+演绎方式 ← Phase E 台词标注来源
    }>
    sfx: string               // ← Phase E 写入对应时间段，不集中放末尾
    bgm: string               // ← Phase E 写具体秒数的卡点，不集中放末尾
  }
}
```

## Phase E：Seedance 提示词生成

> **触发条件**：Phase D 完成后，用户要求生成"即梦提示词"/"Seedance prompt"，或工作流要求完整输出。

### E0-0. 输入要求与信息保全（必读）

**Phase E 的输入必须是 Phase C + D 产出的完整 storyboard**，即含 `screenplay` 与 `panels[]` 的 `EP{XX}-CD-storyboard.json`（或等价结构）。  
**不得仅从 B-clips（片段列表）直接写 Seedance 提示词**，否则会丢失大量信息，导致与「从分镜到提示词」的既定逻辑不一致。

**为何会丢信息：**
- B-clips 只有：clip_id、start/end、summary、location、characters、duration_target。
- 缺少：每个镜头的 description、video_prompt、photographyPlan（灯光/色调/氛围/technicalNotes）、actingNotes（逐人）、audio（dialogue 含 voice_note、sfx、bgm 的精确分配）、以及 screenplay 的逐条 action/dialogue/voiceover。
- 若只凭 summary 脑补时间段与画面，必然丢失上述细节，冲突感、甜度、节奏都会弱化。

**正确流程：**
1. 有 B-clips 后，先跑 **Phase C**（剧本转换 → screenplay.content[]）。
2. 再跑 **Phase D**（分镜规划 → 每个 Clip 的 panels[]，含 description、photographyPlan、actingNotes、audio）。
3. 最后跑 **Phase E**，且 **以 CD-storyboard 为唯一输入**，按下面清单逐 panel/逐时间段转写。

**Panel → Seedance 信息保全清单（转写时逐项核对，不得遗漏）：**

| 来源字段 | 去向 | 说明 |
|----------|------|------|
| `panel.description` | 画面描述 | 情节与构图主体必须进入对应时间段，可压缩不可删 |
| `panel.video_prompt` | 景别/镜头运动/主体 | 提炼 shot_type、camera_move、年龄性别外观 |
| `panel.photographyPlan.lighting` | 本段光线词 | 写成视觉结果（规则7a），如「暗蓝侧光，下颌线轮廓清晰」 |
| `panel.photographyPlan.colorPalette` | 总述或本段色调 | 总述写走势，单段可写当前色调 |
| `panel.photographyPlan.atmosphere` | 总述或本段 | 压迫感/暧昧感等可融进一句描述 |
| `panel.photographyPlan.technicalNotes` | 本段内 | 如「下摇约1.5s完成」「浅景深」「远处人影虚化」 |
| `panel.actingNotes[].acting` | 融入画面描述 | 规则3：只写可见体态/面部状态，不写心理动机 |
| `panel.audio.dialogue[].text` | 对白/内心独白 | 必须完整保留，且标清谁对谁说（规则7） |
| `panel.audio.dialogue[].voice_note` | 语气、情绪、演绎 | 写入 `@图片N[对@图片M，]音色、情绪："..."` |
| `panel.audio.sfx` | 本段音效 | 写在该时间段内，不集中到末尾（规则5） |
| `panel.audio.bgm` | 本段 BGM 卡点 | 写具体秒数，写在该段内（规则6） |
| `screenplay.content[]` | 核对用 | 每条 action/dialogue/voiceover 都应有对应时间段，不可整段消失 |

**多 beat 与多镜头：** 若一个 panel 含多个镜头（如「中远景→特写」）或多个 beat，按规则10 拆成多个子时间段，每段独立写全上述项。

### E0. @图片N 编号分配（角色 + 核心物象）

在生成提示词前，先确定本集所有 `@图片N` 的编号（角色 + 核心道具/物象）：

#### E0-A. 角色编号规则（全剧固定，跨集不变）

```
1. 编号覆盖全剧所有角色（主角 + 所有配角），不限于本集出场角色
2. 排序：先按 role_level（S → A → B → C），同级按首次出场顺序
3. 一旦确定，全剧所有集、所有 Clip 使用同一套编号，绝对不随集数变动
4. 某集未出场的角色直接跳过编号引用，不重新排
```

**全剧角色编号示例（Capital Star Love）：**
```
@图片1 = Kace（S级，男主A）
@图片2 = Zen（S级，男主B）
@图片3 = 林浩（B级，反派经纪人）
@图片4 = 梅森（B级，黑粉头头）
@图片5 = 罗纳德（B级，资本大佬）
@图片6 = 泰亨（B级，男闺蜜）
@图片7 = 伊森（B级，忠犬助理）
@图片8 = 马修（B级，音乐制作人）
```

#### E0-B. 核心物象编号规则（接在全部角色编号之后）

**哪些物象需要 @图片N 参考图：**
1. **跨集反复出现的情感道具**（信物、徽章、戒指等剧情核心道具）
2. **有特定视觉细节必须前后一致的道具**（合同版式/章、特殊器械）
3. **在镜头中占主体的道具特写**（道具是画面主体的段落）

**不需要 @图片N 的物象：**
- 通用背景道具（威士忌杯、办公室文件堆、沙发）
- 一次性出现且无特定细节的道具
- 人物随身服装（已在角色参考图中体现）

**全剧物象编号示例（接在角色8位之后）：**
```
@图片9  = 金色徽章（跨集情感信物，EP01 Panel2/5/22，贯穿全剧）
@图片10 = 契约文件（EP01 Seg3/Seg4 关键道具，有特定版式）
```

#### E0-C. 物象 Seedream 提示词规范

为每个需要 @图片N 的物象生成 Seedream 参考图提示词，格式：

```
物品名：[道具名]
用途：[在剧中出现在哪些关键场景]

#### E0-E. 本段服装风格（必写，避免过度依赖参考图）

每段 Seedance 提示词必须**明确写出**每位出场角色在本段的**服装/造型风格**，不得只写「角色参考图」导致生成时照搬参考图穿着。

**要求（三处都必须写）：**
- **① 图片上传顺序表**：在「内容」列写清「角色参考图 + **本段服装：xxx** + 核心外观」。
- **② 总述**：写一句本段服装（如「本段 @图片1 黑色高定西装，@图片2 晚宴正装」）。
- **③ 每个时间段首次出现该角色时**：将服装关键词嵌入角色描述句中，如「以@图片1为主体参考的**黑色礼服**欧美男性」或「以@图片1（**晚宴礼服**）为主体参考的角色」。**这是最重要的一处**——模型按段生成时不会回看总述，每段每个 beat 都写才能保证全片服装一致。
- 服装描述必须包含**颜色+款式**（可选+核心细节），如「黑色高定西装+深色衬衫解一粒扣」「冰灰礼服外套+黑色高领内搭+细银耳钉」「白色运动T恤+灰色短裤」。**不得只写场合名**（如「晚宴正装」「正式服装」「演出服」），场合名无法约束模型生成具体造型。

- 参考图可能只有一套造型，但剧本里本段是另一套（如晚宴、浴后、运动）时，必须用文字写明本段服装，否则模型会沿用参考图穿着。

**④ 总述中写服装锁定声明（必写）**：在总述服装句之后紧接一句锁定指令，格式：
```
【服装锁定：全段{起止时间}所有角色服装颜色、款式、细节不得有任何改变，每一帧必须与上述描述完全一致，禁止换装、禁止服装细节漂移。】
```
若本段有剧情效果导致的外观变化（如泼酒湿润、流血），在括号内注明「XX为剧情效果，不属于换装」。

**嵌入格式（选一种，保持一段内统一）：**
```
A. 形容词前置：以@图片1为主体参考的黑色礼服欧美男性 / 以@图片2为主体参考的晚宴正装韩式男性
B. 括号补充：以@图片1（黑色礼服）为主体参考的角色 / 以@图片2（晚宴正装）为主体参考的角色
```

**示例（含三处服装写法）：**
```
✅ 图片表 内容：Kace 角色参考图（本段服装：黑色高定西装+金属手表）
✅ 总述：…以@图片1、@图片2为主体参考。本段 @图片1 晚宴黑色礼服，@图片2 正装。色调…

❌ 图片表内容：Kace 角色参考图  ← 未写本段服装

```

### E1. 每个 Clip → 一段 Seedance Prompt

每个 Clip（**固定 15s**）生成一段独立的 Seedance 提示词。

**转换规则（必须全部遵守）**：

#### ⚡ 情绪接力规则（写完整集所有 Seg 后检查）

**每集的 Seg1/2/3 不是三段独立短片，是同一条情绪线的三个节点。**观众看完感觉"少了什么"，99% 是情绪接力断了。

**三个必须检查的接力点：**

**① 集与集之间（上集结尾 → 本集 Seg1 第一帧）**
- 上集最后发生了什么？本集 Seg1 的第一个内心独白必须让观众感受到"隔夜"的情绪余波。
- 不需要回放，一句独白就够：`"He almost kissed me last night. And now I'm making ramen like nothing happened."` 比平静开场贵10倍。

**② Seg1 → Seg2（甜/冲突之后，情绪如何带入下一场）**
- Seg1 结尾角色处于什么情绪状态？Seg2 第一个独白必须携带这个状态，哪怕只是一句话的"余震"。
- 例：Seg1 结尾第一个吻 → Seg2 开头危机来临，Zen 的独白必须让观众感受到"吻后恍惚+危机双重叠加"。

**③ Seg2 → Seg3（为什么角色在这里、做这件事）**
- Seg3 场景切换时，角色的动机必须可感知。用第一帧独白交代"为什么在这个地方、此刻在消化什么"。
- 例：深夜游泳 → 第一帧 `"A kiss. A saved album. Two billion. One day."` 比直接入水有10倍的重量。

**检查方式**：写完全集三段后，把每段第一个独白/台词列出来，连着读一遍。如果能感受到角色的情绪在流动（不是重置），接力成功；如果三段读起来像三个不同角色，接力断了，必须修。

```
❌ 接力断裂（三段情绪各自为政）：
Seg1："Just don't burn it."（平静，与上集无关）
Seg2："Master copy's gone."（冷进入，吻的余震消失）
Seg3：无开场独白（为什么在这里不知道）

✅ 接力流动（情绪递进，有重量）：
Seg1："He almost kissed me last night. And now I'm making ramen like nothing happened."
Seg2："He kissed me an hour ago. And now my master copy is gone."
Seg3："A kiss. A saved album. Two billion. One day."
```

---

#### ⚡ 节奏密度铁律（写任何 Seg 前先检查这条）

**每段 14s 不是电影，是短视频。观众 3 秒无钩子就划走。**

**硬性要求：**
- **每段至少 2 次有声内容**（对白 `dialogue` 或内心独白 `voiceover`，不算背景音效/BGM）
- **连续静默不超过 3s**：任意连续超过 3 秒没有台词/独白，必须补一句内心独白
- **纯气氛段（全无台词/独白）绝对禁止**，哪怕是"浪漫舞池慢舞"也必须有至少 1 句内心独白制造张力

**内心独白是最廉价的节奏救场工具**，随时可用，优先补在：
- 角色做出重要动作前/中（"我在干什么…"）
- 身体接触/目光交汇时（"他的心跳好响"）
- 角色即将做决定/逃跑/说话时（"不能让他看出来"）

```
❌ 禁止（Seg2 全段无对白无独白，14s 哑剧）：
14-18s：搂腰摩挲 ... 音效：舞曲、呼吸。
18-22s：头靠胸口 ... 音效：心跳感。
22-28s：目光交汇 ... 音效：舞曲渐弱。

✅ 正确（每3-4s有一个有声钩子）：
14-18s：搂腰摩挲，以@图片1为主体参考的角色嘴唇轻抿不动，眼神专注落在@图片2脸上，无口型变化。V.O.（@图片1，低哑）："Don't let go."
18-22s：头靠胸口，以@图片2为主体参考的角色嘴唇微合不动，睫毛轻垂，面部维持当前状态无口型变化。V.O.（@图片2，极轻）："His heartbeat is... too loud."
22-28s：目光交汇即将接吻。@图片1对@图片2，极低耳语、蛊惑："Zen."
```

**判断标准**：把本段所有台词/独白列出来，少于 2 条 → 必须补；连续超 3s 无声 → 必须补。

#### 规则1：总述精简（2-3行）+ 本段服装
总述只放：① 画幅+时长+风格总纲 ② @图片N引用声明 ③ **本段每位角色服装风格**（见 E0-E）④ 色调走势预告（若有转场）⑤ "表情丰富有层次，节奏紧凑"。

```
✅ 正确：竖屏9:16，15秒，电影感写实短片。以@图片1为主体参考，本段黑色高定西装+深色衬衫解一粒扣。【服装锁定：全段0-15s服装颜色、款式、细节不得有任何改变，禁止换装、禁止服装细节漂移。】色调：0-7s暗蓝VIP包厢…表情丰富，节奏紧凑。
✅ 多角色：…以@图片1、@图片2为主体参考。本段 @图片1 黑色高定西装，@图片2 冰灰礼服外套+黑色高领内搭。【服装锁定：全段0-14s两人服装不得改变，禁止换装、禁止漂移。】色调…
❌ 错误：只写「以@图片1为主体参考」不写本段服装，导致生成过度依赖参考图穿着
❌ 错误：写了服装但没有锁定声明，模型中途可能漂移（尤其多角色或有大动作的段落）
```

#### 规则2：每个时间段必须含 @图片N 引用 + 服装关键词
不能只在开头提一次，每段都要写「以@图片N为主体参考的角色」。多角色 Clip 各自引用。**同时在首次提及该角色时嵌入服装关键词**（见 E0-E 规则③），确保模型按单段生成时服装不跑偏。

```
✅ 0-0.5s：特写固定，以@图片1为主体参考的黑色礼服欧美男性...
✅ 2-3.5s：以@图片1（黑色礼服）为主体参考的角色手持手机...
❌ 0-0.5s：欧美男性正脸...（缺失 @图片1 引用，角色可能中途跑偏）
❌ 0-0.5s：以@图片1为主体参考的欧美男性...（有引用无服装，服装仍会跑偏）
```

#### 规则3：actingNotes → 融入画面描述（不要单独"演技:"块）

**核心原则：演技描述是"镜头看到什么"，不是"演员在想什么"。**

把 `actingNotes` 的内容**直接融合进画面描述句**，作为视觉状态的一部分，而不是在后面追加"演技：xxx"块。

**禁止写入：**
- 心理动机 / 内心解释（"无意识动作"、"他自己没察觉"、"主动重新武装"、"像在控制"）
- 过于细微无法渲染的动作（"睫毛轻颤"、"指节微白的0.2秒"、"瞳孔扩大"）
- 过程描述（"慢慢压下去"、"努力克制"）→ 只写**结果状态**

**正确写法：把体态/面部状态作为视觉描述词直接写进句子**

```
❌ 旧写法（单独块+心理动机）：
...手指紧握徽章。演技：手指反射性收紧，握力过紧导致指节微白，这是无意识动作他自己没察觉；说台词时嘴角左侧肌肉有微弱拉动像在控制一个要冒出来的嘲弄笑。

✅ 新写法（融入画面描述，只写可见状态）：
...手握金色徽章，握力偏紧，指节略泛白；说第一句台词时嘴角左侧微紧，说完"Funny."后嘴角随即平复，下颌归零。
```

**可以保留的演技描述：**
- 姿态/体态（"脊背挺直"、"步伐加快"、"肩膀微松"）
- 清晰可见的面部状态（"下颌微收"、"嘴角轻抿"、"眼神前锁"）
- 大幅度身体动作（"停步"、"回头"、"摸向口袋"）
- 短暂且明确的表情切换（"嘴角收紧→平复"、"表情瞬间归零"）——用"→"标注前后状态

#### 规则4：photographyPlan → 光影/色调/technicalNotes（逐段写入）
- `lighting` → 写进画面描述的光线词（暗蓝侧光/冷白顶光）
- `colorPalette` → 写进总述的色调预告或各段色调句
- `technicalNotes` → 写进对应时间段（如"下摇约1.5s完成"、"屏幕内容模糊/剪影化"、"需捕捉这0.5s的表情切换"）

#### 规则5：SFX 写入对应时间段，不集中放末尾
```
✅ 0-0.5s：... 音效：极远处演唱会低频音浪若隐若现；暗涌电子bass极轻托底。
✅ 2-3.5s：... 同时叠入手机视频极轻音乐声；BGM音量压到最低。
❌ 末尾集中写"BGM：全段... ；10s BGM暂停..."（时机不精确，AI 忽略率高）
```

#### 规则6：BGM 卡点写具体秒数，写在对应段落内
```
✅ 3.5-5.5s：... BGM在起身动作处（约4.5s）微微上扬。
✅ 8-10s：... 10s整处BGM骤停——绝对静默0.3s。
✅ 13.5-15s：... 13.5s起暗涌电子低频重新渐入渐强，心跳声渐退。
❌ 只在末尾写"BGM过渡"，或写"转场处渐强"（不写具体秒数）
```

#### 规则7：对白格式 —— 全部说出来，禁止 V.O./内心独白

**根本原则：所有音频内容一律用"说出来"的方式，禁止使用 V.O. / 内心独白格式。**

原因：
- V.O. 格式（"不带嘴型"）在 Seedance 实测中难以稳定控制，要么嘴动，要么声音变旁白声
- "说出来"是 Seedance 最可靠的音频生成路径，口型/声音/情绪三者自动对齐

**所有"内心戏"转化为说出来的方式：**

| 原本是内心戏 | 转化为说出来 |
|-------------|------------|
| 角色独自一人时的想法 | 低声自语（喃喃，气声，几乎听不见） |
| 对另一个人的感受 | 转身/背对时轻声说出 |
| 情绪爆发时的内心 | 直接爆发说出口 |
| 眼神交汇时的心跳 | 短句脱口而出，低到只有自己能听见 |

**统一格式：**
```
@图片N[对@图片M，]音色、情绪："内容"
```

**三种说话场景：**

```
① 对另一个人说（对白）：
@图片1对@图片2，低沉磁性、只给他一个人听："Does it hurt?"

② 独自一人喃喃（自语，声音极轻）：
@图片2，轻声喃喃、几乎是气声："Smile. Sign. Don't think about last night."

③ 背对镜头/侧脸时说（嘴型不可见，任意用）：
@图片1，背对，低声："Stay."
```

**内心戏转化示例：**
```
❌ 旧写法（V.O.内心独白）：
V.O.（@图片2声线，轻松心不在焉，不带嘴型）："Smile. Sign. Don't think about last night."

✅ 新写法（低声自语，张嘴说出来）：
@图片2，轻声喃喃、气声、嘴唇微动极轻："Smile. Sign. Don't think about last night."

❌ 旧写法（情绪内心戏V.O.）：
V.O.（@图片2声线，破碎，不带嘴型）："Three years. He's been there the whole time."

✅ 新写法（哑声说出来，哽咽）：
@图片2，极低哑声、哽咽几乎说不出口："Three years..."
```

**⚡ 节奏密度铁律（不变）：**
- 每 15s 段说出来的台词/自语总数 **≥ 2 条**
- 任意连续 **>3s** 无任何台词/自语 → 必须补一句（短句即可）
- **禁止：任何 V.O. / voiceover / 内心独白 / 不带嘴型 写法**

**⚠️ 对白格式说明：**
- **有明确对象**：`@图片N对@图片M，音色、情绪："内容"`
- **无对象（自语）**：`@图片N，轻声喃喃/气声/低语，情绪："内容"`
- **必须标明 @图片N**：多角色场景不标则 AI 无法判断谁在说

#### 规则7a-补充：光影描述 —— 写视觉结果，不写摄影操作

**AI 视频模型不懂灯光指令，只能渲染画面外观。**
```
❌ 摄影操作（AI 无法执行）：
"侧光打出下颌线" / "轮廓光打睫毛和眉骨" / "顶光打亮颧骨"

✅ 视觉结果（AI 能渲染）：
"下颌线在侧光下轮廓清晰锐利" / "五官轮廓分明，眉骨立体，眼部深邃" / "颧骨高光明亮"
```
**转换规则：**
- `X光打Y部位` → `Y部位在X光下[效果]`（轮廓清晰 / 阴影深邃 / 明亮 / 渐暗）
- `侧光打亮半边脸，另一半沉影` → `暗蓝硬侧光，半边脸明亮，另一半沉入阴影`（✅ 已是结果描述）
- `单点光打在物体上` → `物体被单点冷光局部照亮，边缘渐入暗色`

---

#### 规则7b：表情活力 —— 每段写「可见的面部/体态变化」，不写静态标签

**不要用静态形容词，要写动态变化过程（用"→"）：**

```
❌ 死写法（静态标签，AI 生成僵脸）：
表情冷漠，眼神直视。/ 表情克制。

✅ 活写法（写变化过程，AI 知道渲染什么）：
- "嘴角微紧→台词说完后随即平复，下颌归零"（有before/after）
- "停步瞬间脊背绷紧→两步内主动放松，步伐恢复沉稳"（体态变化可见）
- "手摸向口袋→手指轻按确认→手离开，背脊随之挺直"（动作链）
```

**关键规则：**
- 每段至少一个 `[状态A]→[状态B]` 的面部或体态描述（哪怕只是"嘴角轻抿→台词后松开"）
- 优先写**体态变化**（AI视频渲染体态比微表情准确）：站姿、步伐、手部动作、头部角度
- 面部描述只写**结果状态**：`嘴角轻抿`、`下颌前送`、`眼神下移`——不写原因
- 每段演技相关描述总字数控制在 **20字以内**，删掉所有"心理动机"语言

#### 规则8：场景转场 —— 使用空间分界物
跨场景时（如 VIP包厢→后台走廊），单独写一段转场段（约1s），给出明确的空间分界物。

```
✅ 7-8s：转场段。以@图片1为主体参考的角色伸手推开包厢深色门框——门框是明确的空间分界物；身体穿过门框，步态延续；从门框另一侧走出：[新场景光线/色调]。色调从暗蓝翻转到冷白。动作连贯，不硬切。
❌ 7-8s：Kace走进走廊。（无分界物，无转场描述，AI 会硬切或黑屏）

可用的空间分界物：门框 / 通道 / 毛巾遮挡镜头（约0.3s）/ 手遮镜 / 走廊转角
```

色调转场在**总述**和**转场段**两处都要写。

#### 规则9：动作衔接 —— 直接写状态，不加"接上段"标签

相邻时间段之间需要体现动作连续，但**不要用"接上段——"这种无意义的标注**，直接把衔接动作写进画面描述即可：

```
❌ 错误（标签噪音）：
2-3.5s：...接上段——手刚松开徽章，自然移向手机...
8-10s：...接上段——穿过门框后步态延续...

✅ 正确（直接描述状态）：
2-3.5s：...手从徽章自然移向手机，一根拇指极轻划过屏幕...
8-10s：...穿过门框后步态延续，目光前扫，脊背挺直...
```

#### 规则10：Panel 多 beat → 拆成多个子时间段

storyboard 里一个 panel 可能描述多个连续镜头切换（如 panel_6 "中远景→特写"）。翻译成 Seedance 提示词时，**每个镜头 = 一个独立时间段**，不能合并。

```
❌ 错误（一段写两个镜头）：
10-13.5s：中远景（人影出现）→特写（眼部瞳孔扩大）...

✅ 正确（每个镜头独立一段，用"硬切"说明转场方式）：
10-12s：中远景固定，[画面1描述]...
12-13.5s：特写固定（硬切），[画面2描述]...
```

镜头切换关键词：
- `（硬切）` → 两段之间剪辑切换
- `动作连贯不硬切` → 同场景内平滑过渡
- `转场段（空间分界物）` → 跨场景转场

#### 规则11：眼神方向 —— 每段写清楚角色在看什么，不能盯空气

**两种情况，对应两种写法：**

| 场景 | 写法 |
|------|------|
| 镜头本身就是角色的视角目标（开篇正脸特写、对话看向观众） | `直视镜头` |
| 角色在看场景内的具体东西 | 写明目标：`目光朝向走廊尽头人影`、`视线落在手机屏幕上`、`目光朝向门口方向` |

**禁止使用的模糊写法：**
- `眼神前视` / `注视前方` / `眼神疏离` ← 不知道在看什么，AI 生成角色盯空气
- 任何"漂移镜头/无意识看向观众"等过度设计的演技描述 ← 油腻，不自然

**强制规则：**
- **开篇0-0.5s**：主角必须直视镜头（正脸特写的自然视线就是对镜）
- **所有其他段**：目光必须有具体落点（人、物、方向）

#### 规则12：第一帧即人脸，禁止项末尾声明
- 第一帧（0-0.5s）必须是人脸+直视镜头，无空镜
- 末尾加禁止项：`禁止：字幕、水印、logo、任何品牌标志。`
- **版权保护仅在以下情况追加**：画面中出现屏幕/显示器，且屏幕内显示的是**他方真实IP内容**（真实演唱会画面、其他品牌影片、他方歌手表演等）→ 追加`（该屏幕内容模糊/剪影化，避免生成他方IP）`
- **不需要版权保护**：①剧内自创角色的表演（如 Zen 的演唱会身影）②艺术叙事用的逆光剪影③原创道具

### E2.4 ⚡ 版权安全规则（每段提交前必查，触发版权拦截 = 白跑一次）

> Seedance 错误码 `OutputVideoSensitiveContentDetected.PolicyViolation` + "copyright restrictions" = 提示词要求生成了与真实版权内容高度相似的画面。以下词汇/场景会直接触发。

**❌ 禁止词汇（会让模型生成版权敏感视觉内容）：**

| 禁止词 | 原因 | 替换词 |
|--------|------|--------|
| 应援视频截图 | 与真实偶像应援素材相似 | 他的照片（无标识） |
| 演出票根 / 票根 | 真实演出票据有版权信息 | 删除，不提票据 |
| 签名周边 / 周边商品 | 品牌/艺人周边版权敏感 | 删除，不提周边 |
| 应援灯牌 / 灯牌海洋 | 偶像演唱会独有视觉符号 | 现场暖光点缀 / 观众举起发光道具 |
| 签售会 | 偶像文化强关联词，密集使用有风险 | 见面会 / 发布活动 / 签名活动 |
| 演唱会现场 | 真实演唱会画面版权敏感 | 表演现场 / 舞台活动 |
| 专辑签名 / 签名专辑 | 品牌+艺人签名 = 版权物 | 册子上签名 / 在封面签名（不提专辑） |

**✅ 安全替换模板（手机屏幕显示回忆/证明类内容）：**
```
❌ 危险：屏显应援视频截图/演出票根/Zen签名周边一页页滑过
✅ 安全：屏幕上密密麻麻全是他的照片——现场观众视角拍的他、不同时间不同场合、三年时光叠成一页页翻过，无文字无标识，只有人
```

**✅ 安全替换模板（签售/见面会场景）：**
```
❌ 危险：签售会现场灯牌海洋粉丝排队，应援灯牌暖光点缀
✅ 安全：见面会现场观众有序排队等候，现场暖光点缀
```

**检查方式**：提交前搜索提示词中是否出现上表禁止词；出现任何一个必须替换。

### E2.5 ⚡ 内容安全词汇规则（每段提交前必查，触发内容拦截 = 白跑一次）

> Seedance 错误码 `OutputVideoSensitiveContentDetected.PolicyViolation` 另一类来源：**提示词本身含有被平台识别为敏感内容的词汇**，与版权无关，属于内容审核层面。以下词汇在中文语义下具有敏感歧义，必须全局替换。

**❌ 内容安全禁用词：**

| 禁用词 | 触发原因 | ✅ 替换词 |
|--------|---------|----------|
| 高潮 / 高潮帧 / 高潮 beat | 中文语义敏感，平台直接拦截 | 情绪顶点 / 爆发帧 / 关键帧 / 核心 beat |
| 高潮渐入 / 高潮炸入 | 同上 | 情绪顶点渐入 / 爆发点炸入 |
| 情感高潮 / 视觉高潮 | 同上 | 情感顶点 / 视觉爆发点 |
| 婚礼 / 婚礼现场 / 婚礼仪式 | 平台对同性婚礼场景整体拦截 | 庆典 / 私人星空庆典 / 庆典现场 |
| 婚礼西装 / 婚礼正装 | 关联婚礼场景 | 高定正装 / 正式礼装 |
| 礼服西装 / 婚纱礼服 | 同上 | 白色高定正装 / 定制正装 |
| 婚房 | 同性婚姻关联词 | 套房 / 观星套房 / 私人套房 |
| 神父 / 牧师（婚礼语境下） | 宗教 + 同性婚礼组合触发 | 完全删除，改为宾客见证氛围 |
| 誓言（婚礼语境下） | 同上 | 承诺 / 心里话 / 说出的话 |

**检查方式**：提交前在提示词全文中搜索上表所有禁用词；出现任何一个必须替换后再提交。

**在 SKILL.md 自身描述、注释、八角笼检查项等非提示词内容中不受此限制约束，但生成到提示词 ``` 代码块内的内容必须严格遵守。**

### E2.6 ⚡ 八角笼自检（每段写完必跑，不过不输出）

|---|--------|---------|------|
| 1 | **开头3s钩子** | 第一帧有人脸（非空镜）；3s内有明确视觉意外/冲突/肢体接触，观众有"下一秒会发生什么"的悬念 | ☐ |
| 2 | **节奏密度** | 全段对白+内心独白总数 ≥ 2；无任何连续 >3s 的静默段 | ☐ |
| 3 | **情绪峰值** | 每段至少 1 个明确情绪顶点 beat（吻/爆发/护短台词/内心独白破防），该 beat 有对应音效/BGM卡点标注 | ☐ |
| 4 | **服装具体** | 每位角色服装含颜色+款式词，无"晚宴正装""便装""居家服"等模糊场合名；每个时间段首次出现该角色时嵌入服装词 | ☐ |

  camera_move: string         // 镜头运动（如"缓缓推近"）

  video_prompt: string        // 视频生成提示词（用年龄+性别替代角色名）
  characters: Array<{
    name: string              // 角色名
    appearance: number        // 形象编号（对应角色档案）
  }>
  location: string            // 场景名
  scene_type: 'daily' | 'emotion' | 'action' | 'epic' | 'suspense'
  source_text: string         // 对应原文片段
  // 合并自 D2a/D2b
  photographyPlan: {
    lighting: string
    colorPalette: string
    atmosphere: string
    technicalNotes: string    // ← Phase E 必须写入 prompt 对应时间段
  }
  actingNotes: Array<{
    name: string
    acting: string            // 微表情/姿态描述 ← Phase E 必须写入 prompt 演技字段
  }>
  audio: {                    // Phase D3 新增
    dialogue: Array<{
      type: 'dialogue' | 'voiceover'
      character: string
      text: string
      voice_note: string      // 音色+情绪+演绎 ← Phase E 台词标注来源
    }>
    sfx: string               // ← Phase E 写入对应时间段，不集中放末尾
    bgm: string               // ← Phase E 写具体秒数的卡点
  }
}

## 关键原则与注意事项

**视觉物象提取**：
- 优先提取"第一眼能被镜头捕捉"的元素：服装色彩、标志性外貌、场景光线
- 角色介绍中必须说明"我"对应哪个角色（第一人称映射）
- 场景描述不含人物，只描述环境（因为人物和场景要分开生图）
- A1 角色档案额外输出 `age_gender_prompt`（如"二十八岁至三十岁的欧美男性"），Phase D3 的 `video_prompt` 和 Phase E 的角色引用描述都以此为准

**分镜节奏**：
- 情感高潮：多用特写(close-up)、固定镜头
- 动作场景：多用跟随镜头、快速切换
- 日常叙事：中景为主，适当推拉
- 每个 clip 约 4-8 个 panel

**video_prompt 黄金规则（Phase D3）**：
- ❌ 绝不出现角色名："苏晴走进房间"
- ✅ 必须用年龄+性别："二十八岁的东方女性走进宽敞卧室"
- 描述动作先于外貌：先写"做什么"，再写"她的样子"

**Phase E Seedance 快速 checklist**：

| 检查项 | 标准 |
|--------|------|
| **输入来源** | 必须基于 CD-storyboard（含 screenplay + panels[]），不得仅基于 B-clips |
| 信息保全 | 每个 panel 的 description、photographyPlan、actingNotes、audio 均在对应时间段有体现（见 E0-0 清单） |
| 总述行数 | ≤3行 |
| @图片N 引用 | 每个时间段都有 |
| 画面描述 | 每段含体态/面部状态变化（actingNotes 融入），至少一处「状态A→状态B」 |
| 对白格式 | 不写「台词」二字，用 `@图片N[对@图片M，]音色、情绪："内容"`；内心独白用 `@图片N，内心独白、...`；❌ 绝不用"VO" |
| SFX | 写在对应时间段内，非末尾 |
| BGM 卡点 | 写具体秒数，写在对应段落 |
| 场景转场 | 有空间分界物，色调翻转在总述+转场段各写一次 |
| 动作衔接 | 相邻段直接写衔接状态，不加"接上段"标签 |
| 镜头切换 | 多 beat panel 拆成多个子时间段，用「（硬切）」标记切换点 |
| technicalNotes | 写入对应时间段 |
| 第一帧 | 人脸+直视镜头，无空镜 |
| 禁止项 | 末尾声明（字幕/水印/logo/品牌/特殊项） |

**JSON 容错**：
LLM 输出 JSON 时可能有控制字符或引号问题，解析策略：
1. 直接 `JSON.parse()`
2. 转义控制字符后重试
3. 修复中文/英文引号混用后重试
